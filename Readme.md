# 🏥 Hospital App

A Hospital Appointment Management application developed using **Spring Boot**.

## 🛠️ Technologies

* Java
* Spring Boot
* HTML & CSS
* Git & GitHub
* Maven
* Docker
* Jenkins
* AWS EC2

## 🔄 DevOps Pipeline

```text
GitHub
   ↓
Jenkins
   ↓
Maven Build
   ↓
Docker Build
   ↓
Docker Container
   ↓
AWS EC2 Deployment
```

## 📌 Project Objective

To implement an end-to-end **CI/CD and containerized deployment workflow** for a Spring Boot application using Jenkins, Docker, and AWS EC2.
